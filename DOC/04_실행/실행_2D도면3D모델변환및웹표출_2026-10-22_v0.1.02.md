## 2. 세부 수정 내역 및 구현 결과

### 2.1 좌측 바 UI 수정
1. **적용배근도/구조도 테이블 삭제**: 좌측 바 상단 `#step3-rebar-summary-card` 완전 제거, 구조물 선택 리스트를 최상단에 배치.
2. **구조물 텍스트 1.5배 확대**: `.struct-card-step3-title` 폰트 크기를 기존 대비 1.5배인 `17.5px !important` (굵기 700)로 확대.
3. **'3D 철근 투시 및 표현제어' 패널 이동**: 기존 우측 플로팅 HUD에서 좌측 바 구조물 선택 패널 하단으로 이동 배치하여 뷰포트 가림 방지.

### 2.2 우측 창 UI 수정
1. **철근 상세 정보 표시 조건**: 철근이 선택된 경우에만 플로팅 카드를 표출(`display: flex`), 미선택 시에는 완전 숨김(`display: none`).
2. **철근 번호 텍스트 1.5배 확대**: 상세 정보 창 상단 철근 번호(`#step3-detail-title`)를 `18px !important` (굵기 800, 황금색 골드 `#facc15`)로 확대. 소속 날개벽 제원 및 중량 강조.

### 2.3 우측 메인창 UI 및 상호작용 기능 수정
1. **불필요한 안내 문구 제거**: `[3단계: 배근도 기반 3D 철근배근]` 뱃지 및 `좌클릭: 회전 | 우클릭: 이동 | 휠: 줌...` 오버레이 칩 제거.
2. **초기 선택 구조물 '암거본체' 설정**: 3단계 진입 시 기본 선택 구조물을 `'CULVERT'`로 설정하고, 3D 모델 위에 "종점부 좌측 날개벽", "종점부 우측 날개벽" 2개 명칭만 깔끔하게 표출. 암거본체의 철근 상세 정보나 불필요한 단면 마커는 미표시.
3. **3D 텍스트 크기 화면상 고정 (Constant Screen Size)**: Three.js 렌더 루프(`animate()`)에서 카메라와 텍스트 스프라이트 간의 거리에 비례하여 `scale.set(dist * 0.040 * aspect, dist * 0.040, 1)`로 동적 스케일링. 마우스 휠로 줌 인/줌 아웃을 수행해도 텍스트 크기가 확대/축소되지 않고 모델 가림 방지.
4. **날개벽별 철근 선택 및 활성화 분리 (최우선 과제)**:
   - 철근 선택 및 활성화는 현재 선택된 날개벽(`wingwallId`)에 완전 종속.
   - 특정 날개벽에서 철근을 클릭하면 오직 해당 날개벽에 속한 철근만 골드(`#facc15`) 하이라이트 및 3D 라벨 표시.
   - 타 날개벽의 동일 기호 철근은 `opacity: 0.10, color: #64748b`로 비활성화.
   - 좌측 바에서 날개벽을 변경하면 이전 철근 선택 상태 및 상세 정보 창을 즉시 초기화.
5. **3D 모델 기본 구도 변경 조건 수정**:
   - 사용자가 회전/이동 조작 후 빈 바닥 영역을 클릭하더라도 카메라 시점을 절대 리셋하지 않고 사용자의 시점 유지.
   - 좌측 바에서 날개벽 카드를 직접 클릭한 경우에만 해당 날개벽을 중심으로 기본 구도(시점) 전환.
