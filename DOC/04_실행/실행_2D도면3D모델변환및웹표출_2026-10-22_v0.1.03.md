## 2. 세부 수정 내역 및 구현 결과

### 2.1 좌측 바 UI 수정
1. **불필요한 테이블 삭제**: 좌측 바의 ‘적용 일반도 정보 & 체적 요약’ (`#step2-general-dwg-card`) 및 ‘평면도 부재 판별 현황’ 패널을 완전 삭제.
2. **구조물 선택 텍스트 1.5배 확대**: `.struct-card-step2-title`에 `font-size: 17.5px !important; font-weight: 700;`를 적용하여 날개벽 명칭 텍스트를 1.5배로 확대하고 '3D 구조물 선택'으로 섹션명을 통일.

### 2.2 우측 메인창 UI 및 기능 수정
1. **불필요한 안내 텍스트 완전 제거**:
   - 뷰포트 상단 도면 탭(`#viewport-drawing-tabs`)을 2단계에서 숨김 처리(`display: none`).
   - 상단 스텝 뱃지(`[2단계: 일반도 전용 외형 모델]`) 삭제.
   - 메인 화면 오버레이 조작 안내(`좌클릭: 회전 | 우클릭: 이동 | 휠: 줌...`) 문구 완전 삭제.
2. **초기 선택 구조물 '암거본체' 설정 및 단면 0-0 표기 삭제**:
   - 2단계 진입 시 `selectObject('CULVERT')`를 자동 호출하여 암거본체가 기본 선택되도록 설정.
   - 암거본체 선택 시 날개벽 구조물 명칭("종점부 좌측 날개벽", "종점부 우측 날개벽")만 3D 모델 위에 깔끔하게 표출.
   - "단면 A-A", "단면 B-B", "단면 C-C", "단면 D-D" 등 단면 0-0 텍스트 표기 및 EL 마커를 완전 미생성/삭제.
3. **텍스트 크기 고정 (Screen-space Constant Size)**:
   - Three.js 렌더 루프(`animate()`)에서 카메라 거리에 비례하여 텍스트 스프라이트를 동적 스케일링(`dist * 0.040`). 휠 줌 조작 시에도 텍스트 크기가 일정하게 유지되어 모델 가림 방지.
4. **메인 화면 모델링 크기 조정 (약 80% 화면 점유)**:
   - `fitView(coverage = 0.80)` 함수에서 3D 모델 전체 바운딩 구(Bounding Sphere)의 반경과 카메라 화각(FOV), 뷰포트 종횡비(Aspect)를 연립 계산하여 모델이 메인 화면 표시 영역의 약 80%를 안정적으로 차지하도록 카메라 거리를 정밀 산출.
   - 2단계와 3단계 모두 동일하게 80% 기준을 적용.
