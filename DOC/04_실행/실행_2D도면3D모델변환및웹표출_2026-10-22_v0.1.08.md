## 1. 리팩토링 개요 및 목적

- **원칙 준수**: 기존 모든 기능, API 인터페이스, 3D 모델링 기하학, UI 상호작용 로직은 **100% 동일하게 유지** (동작 변경 일절 없음).
- **공통화 (DRY)**: 중복 생성되던 치수선 LineSegments 및 텍스트 Sprite 씬 등록 로직, Flask 도면 분류 로직 헬퍼화.
- **클린 코드**: 미사용 모듈 import, 미사용 변수 제거 및 파일 핸들/임시 파일 리소스 누수 방지.
