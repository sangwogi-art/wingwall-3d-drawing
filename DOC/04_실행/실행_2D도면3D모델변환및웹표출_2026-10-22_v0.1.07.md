## 1. 개요 및 배경

- **업무 명칭**: 3단계 철근 3D 모델링 수정 – **W1 철근** 형상 수정
- **문제 원인 분석**:
  - 기존 [`rebar_model.py`](file:///e:/11.%202026%20PROJECT/30%20도면을%203D로%20구현/01%20대산당진_수로암거(STA13+611)_옹벽형날개벽/Code/3d-drawing/rebar_model.py#L278-L285)에서 `w1_bars` 생성 시 4개의 정점(저판 하면 끝점 $\rightarrow$ 저판 하면 `u_stem_front + 0.06` $\rightarrow$ 벽체-저판 접합부 `h_foot_top`의 `u_stem_front` $\rightarrow$ 벽체 상단 `z_stem_top`의 `u_stem_front`)으로 구성되어 있었음.
  - 이로 인해 벽체와 저판이 만나는 접합부(`h_foot_top`)에서 저판 하면으로 내려갈 때 `+0.06m`만큼 횡방향 편차가 발생하여 접합부에서 한 번 꺾이고 저판 하면에서 또 한 번 꺾이는 이중 꺾임 현상이 나타남.
- **수정 목표**:
  - 벽체와 저판이 만나는 접합부(`h_foot_top`)의 불필요한 꺾임을 제거.
  - 벽체 내부에 배근된 W1 철근의 긴 구간이 기존 방향(`u = sec['u_stem_front']`)을 그대로 유지한 직선으로 저판 하면까지 연장되도록 수정.
  - 오직 **저판 하면(`z = sec['z_foot_bot'] + 0.016`)에서만 1회 꺾이는 ㄱ자 형태**로 구현하고, 타 철근은 일절 변경하지 않음.

## 2. 세부 수정 내역

### 2.1 W1 철근 3D 폴리라인(Polyline) 기하 수정 ([`rebar_model.py`](file:///e:/11.%202026%20PROJECT/30%20도면을%203D로%20구현/01%20대산당진_수로암거(STA13+611)_옹벽형날개벽/Code/3d-drawing/rebar_model.py#L278-L285))
- **수정 전 (4정점, 2회 꺾임)**:
  ```python
  w1_bars.append([
      to_world(s, max(sec['u_toe_rebar'] + 0.02, sec['u_stem_front'] - 0.200), sec['z_foot_bot'] + 0.016),
      to_world(s, sec['u_stem_front'] + 0.06, sec['z_foot_bot'] + 0.016),
      to_world(s, sec['u_stem_front'], sec['h_foot_top']),
      to_world(s, sec['u_stem_front'], sec['z_stem_top'])
  ])
  ```
- **수정 후 (3정점, 저판 하면 1회 꺾임 ㄱ자 형상)**:
  ```python
  w1_bars.append([
      to_world(s, max(sec['u_toe_rebar'] + 0.02, sec['u_stem_front'] - 0.200), sec['z_foot_bot'] + 0.016),
      to_world(s, sec['u_stem_front'], sec['z_foot_bot'] + 0.016),
      to_world(s, sec['u_stem_front'], sec['z_stem_top'])
  ])
  ```
  - **정점 0 (저판 하면 끝단)**: 기존과 동일한 저판 하면 정착부 위치 유지 (`z = sec['z_foot_bot'] + 0.016`).
  - **정점 1 (저판 하면 유일 꺾임점)**: 벽체 내부 배근선(`u = sec['u_stem_front']`)이 직선 그대로 내려와 저판 하면(`z = sec['z_foot_bot'] + 0.016`)과 만나는 지점.
  - **정점 2 (벽체 상단 끝단)**: 기존과 동일한 벽체 상단 위치 유지 (`u = sec['u_stem_front']`, `z = sec['z_stem_top']`).
  - 접합부(`h_foot_top`) 중간 정점과 `+0.06` 오프셋을 제거하여 벽체 상단부터 저판 하면까지 **완벽한 단일 직선**으로 연결됨.
