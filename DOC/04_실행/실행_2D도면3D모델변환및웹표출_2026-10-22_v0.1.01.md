## 2. 3단계 UI 개편 상세 내역

### 2.1 세로 2단 레이아웃 일관성 확보
- **레이아웃 통일**: 기존의 좌·중·우 3열 배치에서 2단계와 완전히 동일한 **좌측 제어 패널(420px) + 우측 3D 뷰어(전체 폭)** 세로 2단 레이아웃으로 전면 개편.
- **도면 확인 탭 및 미리보기 삭제**: 3단계 진입 시 불필요한 2D 도면 확인 탭과 2D 캔버스 뷰어를 제거하고 3D 모델링 공간을 최대화.

### 2.2 좌측 UI: 구조물 중심 선택 체계
- **표시 구조물**: 실제 도면에 표기된 부재만 선별 표출 (시점부 임의 생성 방지 지침 준수)
  1. `암거 본체 (STA.13+611.21)`: 클릭 시 전체 보기(`fitView()`), 모든 부재 정상 표출
  2. `종점 좌측 날개벽 (L=4.35m)`: 클릭 시 해당 날개벽 중심 3D 카메라 확대 Focus
  3. `종점 우측 날개벽 (L=5.40m)`: 클릭 시 해당 날개벽 중심 3D 카메라 확대 Focus
- **3D 상호작용 및 시각적 위계**:
  - **선택된 날개벽**: 콘크리트 외형 및 내부 19종 철근을 정상 색상과 선명도(100%)로 강조.
  - **비선택 구조물 (암거 및 반대편 날개벽)**: 모델에서 완전히 숨기지 않고 투명도(0.08) 및 옅은 그레이(0.12)로 비활성화하여 위치·형상 참고 가능 상태 유지.

### 2.3 우측 UI: 3D 모델 뷰어 및 인터랙티브 HUD
- **철근 기호 상세 제원 플로팅 카드**:
  - 평상시(미선택): 화면을 가리지 않도록 완전 숨김(`display: none`).
  - 3D 철근 클릭 시: 우측 상단 플로팅 카드로 즉시 표출 (기호, 직경 SD400, 배근 부위, 간격/피복, 좌/우 본수 및 길이, 중량, 철근 절곡 상세 형상 SVG).
  - 닫기(`✕`) 버튼 또는 배경 클릭 시 즉시 닫힘.
- **3D 철근 투시 및 표현 제어 HUD**:
  - 콘크리트 외형 투명도(X-Ray) 슬라이더 (0.05 ~ 0.90)
  - 철근 굵기 표현 배율 슬라이더 (1.0x ~ 3.0x)
  - 직경별(H19 빨강, H16 파랑, H13 초록) 원클릭 필터 필
  - 부위별(우각부, 벽체, 저판, 헌치) 원클릭 필터 필
  - 원클릭 접기/펼치기(`▾`/`▸`) 토글 지원
- **철근 재료표 및 배근 내보내기**:
  - `📊 전체 철근 재료표 (BOM) 보기` 모달 연동
  - CSV / OBJ / STL / DXF 내보내기 퀵 액션 그리드 배치
