## 1. 개요 및 목적

사용자가 터미널 명령어 입력 없이 Windows 탐색기에서 더블클릭 한 번으로 3D CAD/BIM 모델러 프로그램 백엔드를 자동 점검·구동하고 웹 브라우저(`http://localhost:5000`)를 즉시 열어볼 수 있는 원클릭 실행 파일 및 바로가기 링크를 제공합니다.

---

## 2. 생성된 실행 파일 및 바로가기 구성

1. **`[실행]_암거및날개벽_3D외형배근모델러.bat`**:
   - 포트 `5000`의 수신 대기(Listening) 상태를 우선 검사
   - 이미 서버가 구동 중인 경우: 즉시 기본 웹 브라우저(`http://localhost:5000/`)를 실행하고 종료
   - 서버가 정지된 경우: WSL2 Ubuntu 가상환경(또는 Windows Python 환경)에서 백그라운드 서버를 자동 기동 후 브라우저 오픈
   - UTF-8 인코딩 및 안전한 딜레이 처리 적용
2. **`[실행바로가기]_암거및날개벽_3D외형배근모델러.lnk`**:
   - Windows 셸 단축 아이콘으로 더블클릭 시 위 배치 실행기를 호출
3. **`[바로가기]_3D모델러_웹접속.url`**:
   - 웹 서버가 동작 중일 때 원클릭으로 웹 브라우저 3D 뷰어 창을 띄우는 인터넷 바로가기
